# Quantum Computing, From a Laptop

Three runnable Jupyter notebooks that answer a simple question: **can you actually do quantum computing — on real quantum hardware — from an ordinary laptop, and can it touch genuine, classic science problems?**

All three notebooks are self-contained, run entirely on the free local simulator (`qiskit-aer`), and every plot/number in them was generated by actually executing the code — nothing here is a mockup. Each also shows the exact (small) code change needed to point the same circuits at a real IBM quantum processor.

## What's inside

### `notebooks/01_quantum_computing_on_a_laptop.ipynb`
An introduction to running real quantum hardware from a notebook, plus three foundational quantum-information demos:

- **Bell state entanglement** — the two-qubit correlations that have no classical analogue.
- **CHSH Bell-inequality test** — an actual experimental test of local realism. The simulated experiment measured **S = 2.860**, clearly violating the classical bound of 2 and sitting right at the quantum (Tsirelson) limit of 2√2 ≈ 2.828.
- **GHZ states** (3, 5, 8 qubits) — multipartite entanglement, the standard way quantum hardware providers benchmark chip quality.
- **VQE for a transverse-field Ising model** — a real condensed-matter ground-state calculation, matching exact diagonalization to 5.87×10⁻⁵.
- A worked example of swapping the simulator for a real IBM Quantum backend, and free-tier access notes.

### `notebooks/02_classic_physics_with_quantum_help.ipynb`
Four classic problems, one from each major area of physics — each solved the normal (classical) way, then reproduced with a quantum computation of the same physical quantity:

| Area | Classic problem | Quantum technique | Result |
|---|---|---|---|
| Optics | Mach-Zehnder / double-slit interference | A single qubit as a 2-path interferometer | Matches the classical cos²(φ/2) law to within shot noise |
| Nuclear/atomic physics | Exponential decay law N(t) = N₀e^(−λt) | The qubit's own real amplitude-damping (T1) decay | Fitted λ = 0.04114 vs. theoretical 0.04082 |
| Quantum mechanics | Schrödinger equation (finite-difference grid + diagonalization) | Quantum Phase Estimation | Recovers the exact ground-state energy (0.95851) |
| Statistical mechanics / magnetism | Spin-spin correlation vs. field, 2-spin Ising model | Variational Quantum Eigensolver (VQE) | Matches exact diagonalization at every field value |

### `notebooks/03_astronomy_with_quantum_help.ipynb`
Three classic problems from observational astronomy and cosmology, again solved the normal way and then with quantum help:

| Problem | Classic method | Quantum technique | Result |
|---|---|---|---|
| Period finding (variable stars, transiting exoplanets) | Discrete Fourier transform / Lomb-Scargle periodogram | Quantum Fourier Transform | Recovers the exact same period from a noisy synthetic light curve |
| Cosmological parameter fitting (χ² grid, à la a Hubble-diagram fit) | Grid search / χ² minimization | Grover's search algorithm | Finds the same best-fit Ωm as an 8-point classical grid scan, using only 2 amplitude-amplification rounds (94% success probability) |
| Exoplanet transit-probability estimation | Monte Carlo with a classical PRNG | Monte Carlo using measured quantum superpositions as the random source | Both converge to the analytic transit probability R★/a |

## Quick start

```bash
pip install -r requirements.txt
jupyter notebook notebooks/
```

All three notebooks run offline, with no account or API key required.

## Running on real quantum hardware

IBM Quantum's free "Open Plan" gives every account real QPU time (their current 127+ qubit processors) — about 10 minutes per rolling 28-day window as of 2026. Notebook 1, Section 5 shows the exact code path:

```python
from qiskit_ibm_runtime import QiskitRuntimeService, SamplerV2 as Sampler

QiskitRuntimeService.save_account(channel="ibm_quantum_platform", token="<your free API token>")
service = QiskitRuntimeService()
backend = service.least_busy(operational=True, simulator=False)

isa_circuit = transpile(my_circuit, backend, optimization_level=3)
job = Sampler(mode=backend).run([isa_circuit], shots=4096)
```
